# 钢板套料与流水线均衡工具

这是一个独立的 Visual Studio 2022 / Qt Widgets 项目，使用提供的 QXlsx 1.4.6 读取和输出 Excel。

程序支持两类输入：

1. 原始工件表：先根据参数分组并完成一维套料，再调整整张钢板的生产顺序。
2. 已有“钢板明细”：保持每张钢板内部工件不变，只重新排列整张钢板。

输入模式默认设置为“自动识别”。

## 完整流程

1. 读取 Excel 和 JSON 参数。
2. 将规格解析为“厚度 + 宽度”。源数据中通常写成“宽度*厚度”，例如 `22*3`。
3. 按启用的硬条件分组：材质、厚度、宽度。
4. 根据默认钢板长度或规格覆盖规则进行一维套料。
5. 先用 Best Fit Decreasing 确定钢板数量。
6. 保持钢板数量不变，按照长度从大到小重新分配工件，并均衡 600、900 等长度区间的工件数量。
7. 汇总每张钢板的坡口、人工焊和机器焊负荷。
8. 按用户设置的优先级调整整张钢板顺序。
9. 输出 48 列“钢板明细”，并复核工件数、钢板数和容量。

## 可调参数

### 分组和套料

- 是否按材质分组。
- 是否按厚度分组。
- 是否按宽度分组。
- 默认钢板长度，默认 `6000 mm`。
- 按材质、厚度、宽度设置不同钢板长度。
- 切缝宽度。
- 每张钢板首尾余量合计。
- 长度分界值列表，默认 `0`（不启用长短分界）；需要时可填写 `600` 或 `600,900`。

钢板长度覆盖规则中的空白材质、0 厚度、0 宽度表示任意值。优先级数字越小越先匹配；优先级相同时，条件更具体的规则优先。

### 焊接路线

- 人工焊宽度范围，默认 `22-34`。
- 机器焊宽度范围，默认 `42-60`。
- 支持多个范围，例如 `22-34,70-80`，也支持 `22至34` 的写法。
- 没有匹配任何列表的搭焊会作为“未分类焊”显示，便于补充参数，不会被静默忽略。

### 流水线均衡

坡口、人工焊、机器焊均可单独设置：

- 是否启用。
- 优先级。
- 同优先级内的权重。
- 允许偏差。

程序采用分级比较：先比较最高优先级；在允许偏差内视为相同，再比较下一级。因此低优先级不会为了少量改善而明显破坏高优先级结果。

每个目标同时检查：

- 从生产开始到任意位置的累计进度是否接近全程平均进度。
- 连续两张高负荷钢板是否堆积。
- 连续若干张钢板的窗口负荷是否过高。

## 界面使用

1. 双击 `运行钢板套料与流水线均衡.cmd`，或直接运行 `bin/x64/Release/SteelPlateSequenceOptimizer.exe`。
2. 选择输入 Excel。
3. 选择输入模式，通常保留“自动识别”。
4. 在“套料与规格参数”中设置分组、钢板长度和焊接路线。
5. 在“流水线优先级”中设置三个目标的优先级。
6. 点击“分组套料并优化顺序”。
7. 检查预览和调整前后指标，然后导出最终 Excel。

界面参数可保存为 JSON，下一批数据可以直接加载。

## 编译

1. 使用 Visual Studio 2022 打开 `SteelPlateSequenceOptimizer.sln`。
2. 选择 `Release | x64`。
3. 生成解决方案。
4. 输出目录为 `bin/x64/Release`。

QXlsx 头文件、库文件和 DLL 位于 `third_party/QXlsx-1.4.6-win64-release`。构建后会自动复制 QXlsx、参数文件和 Qt 运行库。

## 命令行

```text
SteelPlateSequenceOptimizer.exe --input 输入.xlsx --output 输出.xlsx --config config/default.json
```

返回码为 0 表示成功。失败时会在输出路径旁生成 `.error.txt`。
