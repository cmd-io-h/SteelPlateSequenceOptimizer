# 排产规则

本文记录当前代码采用的套料、钢板顺序优化和时序模拟规则，当前流程只适用于小径工件

## 一、数据识别

### 管径范围

- 小径，宽度小于 `76 mm`，进入当前计算
- 中径，宽度为 `76–114 mm`，当前过滤
- 大径，配置默认范围为 `140–377 mm`，当前过滤

小径工件再按宽度确定接焊路线

- `22–34 mm`，人工接焊
- `42–60 mm`，机器接焊
- 未落入人工或机器范围的工件不进入接焊路线

### 组队数量

排产表中的 `组队` 为搭焊、对焊和套管次数的合计，结果以数值写入 Excel，便于直接求和

- 一个搭焊、对焊或套管记 `1`
- 同一单元格出现两个有效标记记 `2`
- 空白或没有有效标记记 `0`
- `H`、`W` 按坡口标记处理，不计入组队

## 二、套料规则

### 分组硬条件

默认按材质、厚度和宽度分组，同组工件使用相同钢板长度，同一次计算默认钢板长度为 `6000 mm`

### 确定钢板数量

先将工件按长度从大到小排列，使用 Best Fit Decreasing 放入剩余空间最合适的钢板，得到不增加钢板数量的基准结果

### 同组重新分配

钢板数量确定后，在容量约束内重新分配同组工件，主要比较

1. 坡口工序负荷
2. 人工组队和内外圈人工接焊负荷
3. 机器组队和内外圈机器接焊负荷
4. 后续工序工件数量
5. 钢板已用长度和工件数量

局部搜索会尝试工件移动和交换，任何候选结果都必须满足钢板容量，并且不得产生空钢板

### 钢板内工件顺序

原始工件表生成套料时，钢板内先交替有坡口和无坡口，再尽量交替有接焊和无接焊，同条件下保持长度优先

已有钢板明细输入时，不改变钢板内工件归属和顺序

## 三、钢板顺序优化

排产阶段只调整整张钢板，同一钢板组内允许交叉排列，不跨组移动，钢板内工件固定

候选顺序按优先级逐层比较

1. 缓冲区堵塞，只有缓冲区满后外圈工位无法释放工件的时间计入堵塞
2. 人工、机器和无接焊钢板按总量比例动态穿插，避免同一路线连续集中
3. 坡口负荷，比较工件级累计进度、相邻高负荷和滚动窗口峰值
4. 接焊负荷，人工和机器路线分别比较工件级累计进度、工位等待和滚动窗口峰值
5. 组队、外圈接焊和内圈接焊的排队等待

优先级较高的指标先比较，在允许偏差内视为相同后再比较下一层，避免低优先级的小幅改善破坏高优先级结果

## 四、时序流程

工件流程为

```text
喷码 → 切割 → 可选坡口 → 可选组队 → 外圈接焊 → 中间缓冲 → 内圈接焊 → 分拣完成
```

### 喷码和切割

- 整板喷码总时间为 `102 + 喷码增量 × 工件数`
- 默认喷码增量为 `18 s`
- 下一张钢板可在上一张钢板喷码完成后进入喷码
- 切割必须等上一张钢板全部工件切完并完成钢板回位
- 工件切割开始时间不得早于该工件喷码完成时间

### 坡口和组队

- 长度小于默认 `600 mm` 的工件直接离线，不进入下游工序
- 有坡口标记的工件进入坡口工位，默认单件 `85 s`
- 组队数量大于零的工件进入组队工位，默认单件 `160 s`

### 接焊

人工和机器接焊是两条独立路线，每条路线都包含外圈和内圈两道串行工序

- 人工单道接焊默认 `178 s`
- 机器单道接焊为 `109 + 宽度 × 3.14 ÷ 5` 秒
- 外圈和内圈分别计算一次相同的单道时间
- 每条路线的外圈与内圈之间各有一个容量为 `3` 的缓冲区
- 缓冲区未满时只记录工件等待，不计堵塞
- 缓冲区已满且外圈工位不能释放工件时，外圈完成到释放之间的时间计为堵塞

### 分拣区间

进入分拣时间取工件开始喷码时间，完成分拣时间取该工件全部实际工序完成时间，用于观察工件从进入流水线到完成的总历时

## 五、利用率

### 单张钢板

```text
单板利用率 = 单板已用长度 ÷ 单板长度
```

### 立库分组

```text
分组平均利用率 = 分组已用长度合计 ÷ Σ(钢板长度 × 钢板数量)
```

排产表按工件逐行展示，同一钢板的利用率只在钢板首行显示，计算排产平均值时应按钢板首行取值，不能按全部工件行重复统计
